Como fazer commit e push?

Para fazer um commit e push no Git, siga os passos abaixo:

  1. Abra o terminal ou prompt de comando.
  2. Navegue até o diretório do seu repositório local usando o comando cd.
  3. Adicione os arquivos que você deseja incluir no commit usando o comando: 
    git add nome_do_arquivo
    ou para adicionar todos os arquivos modificados: 
    git add .
  4. Faça o commit das suas alterações com uma mensagem descritiva usando o comando: 
    git commit -m "Sua mensagem de commit"
  5. Envie suas alterações para o repositório remoto usando o comando: 
    git push origin nome_da_branch
    Substitua nome_da_branch pelo nome da branch onde você deseja enviar as alterações (geralmente é main ou master).

Pronto! Você fez um commit e push com sucesso.
